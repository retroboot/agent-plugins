# Core Labels

Standard label set to bootstrap into any new repository. Used by `init` Phase 2.

Each label: `name | color (hex, no #) | description`

---

## Type

| Name | Color | Description |
|------|-------|-------------|
| `bug` | `d73a4a` | Something isn't working |
| `feature` | `0075ca` | New functionality |
| `enhancement` | `a2eeef` | Improvement to existing functionality |
| `chore` | `e4e669` | Maintenance, deps, tooling |
| `documentation` | `0052cc` | Documentation only |
| `refactor` | `d4c5f9` | Code restructuring without behavior change |
| `breaking change` | `b60205` | Introduces a breaking API or behavior change |
| `security` | `e11d48` | Security-related fix or concern |

## Priority

| Name | Color | Description |
|------|-------|-------------|
| `P0` | `b60205` | Critical — drop everything |
| `P1` | `d93f0b` | High priority |
| `P2` | `e4e669` | Normal priority |
| `P3` | `bfd4f2` | Low priority / nice to have |

## Community

| Name | Color | Description |
|------|-------|-------------|
| `good first issue` | `7057ff` | Good for newcomers |
| `help wanted` | `008672` | Extra attention needed |

## Status

| Name | Color | Description |
|------|-------|-------------|
| `blocked` | `e4e669` | Blocked on external dependency |

## Size

| Name | Color | Description |
|------|-------|-------------|
| `size:xs` | `ededed` | Trivial — < 30 min |
| `size:s` | `ededed` | Small — < 2 hours |
| `size:m` | `ededed` | Medium — half day |
| `size:l` | `ededed` | Large — 1–2 days |
| `size:xl` | `ededed` | Extra large — needs breakdown |
